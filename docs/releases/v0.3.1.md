A Windows-focused update: everything found in a final review of how StarCadence behaves on real Windows PCs, plus a Support link.

**Downloads** (below): `StarCadence-windows.zip` (Windows 10/11), `StarCadence-mac.zip` (Apple Silicon), `StarCadence-linux.tar.gz`, and `StarCadence-nina-plugin.zip` (N.I.N.A. 3.2 or newer). Unzip and double-click StarCadence; see the README for the one-time security prompt on each system.

### Windows
- The PC no longer goes to sleep in the middle of a night run (app, command line and N.I.N.A. plug-in). The screen may still turn off. Same on Mac and Linux.
- Clicking inside StarCadence's black window can no longer freeze it (Quick Edit is turned off), and the window title says when a night is running.
- If StarCadence cannot start, the message stays on screen instead of the window vanishing (on a Mac, an alert explains it). Windows' Controlled folder access and Smart App Control are explained in the README.
- Settings and history files cope with being held open for a moment by OneDrive, antivirus or the app window; a history file that cannot be written no longer fails targets or makes them repeat.
- Target lists saved from Excel in decimal-comma languages (semicolon columns, `12,5`) now load correctly.
- Pressing Ctrl+C during a run finishes the current step and parks before quitting.

### N.I.N.A. plug-in
- The zip now has the plug-in files at the top, so **Extract All** and N.I.N.A.'s own installer put them where N.I.N.A. looks. Install steps updated in the plug-in README.
- Clearer message when plate-solve centring fails; the PC is kept awake during the night.
- The manifest for N.I.N.A.'s plug-in repository is attached separately (`StarCadence-nina-manifest.json`) and matches the zip.

### Support
StarCadence is free and open source. The new **Support** button in the app opens the [Support section](https://github.com/TechAmatuer/StarCadence#support-starcadence) of the README.

### Testing
48 automated tests on Windows, macOS and Linux, plus the whole suite again on Windows under Portuguese, German, Thai and Turkish formats; the packaged program's app window is started and used on all three systems; a night is run through a real INDI server on Linux.
