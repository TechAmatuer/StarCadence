StarCadence inside N.I.N.A. now behaves like Target Scheduler, and can measure exposures like the ExoPlanets plug-in.

**Downloads** (below): `StarCadence-windows.zip`, `StarCadence-mac.zip` (Apple Silicon), `StarCadence-linux.tar.gz`, and `StarCadence-nina-plugin.zip` (N.I.N.A. 3.2 or newer). To update the plug-in, close N.I.N.A., replace the folder you copied last time, and start N.I.N.A. again.

### N.I.N.A. plug-in
- **Triggers now fire during a StarCadence night.** Meridian Flip, Autofocus After..., Dither After Exposures and Center After Drift, placed on the StarCadence Night instruction or anywhere above it, are checked before and after every slew, filter change and exposure, and see the current target, exactly as N.I.N.A.'s own sequencer does. Before this release they did not run while StarCadence Night was running, so **an equatorial mount was not flipped at the meridian**: please update.
- **Before each target / After each target**: two drop areas on the instruction for your own N.I.N.A. steps (autofocus on the target, a dome wait, a settle), run on every target after the slew or centring and after its exposures.
- **Waiting no longer leaves the mount tracking.** While StarCadence waits (for a transit window, or for a target to rise), guiding and tracking are stopped, as Target Scheduler does; tick **Park while waiting** to park during waits of 10 minutes or more.
- **Measure exposure** (optional): once a night per target and filter, a test frame after centring sets the exposure so the target star's peak lands at the share of the camera's range you choose (60% by default), like the ExoPlanets plug-in's *Calculate Exposure Time*, but for every target in the night.
- If StarCadence has no horizon of its own, the N.I.N.A. profile's custom horizon is used.

### Mac and Linux (INDI)
- Tracking is turned off while waiting, and back on with the next slew.

### Documentation
- The README now compares StarCadence with Target Scheduler and ExoPlanets, feature by feature, including what StarCadence does not do (image grading, flats per target, comparison-star lists, mosaics).

### Testing
- New: whole nights run inside N.I.N.A.'s own sequencer classes on GitHub's Windows machines, with stand-in equipment, checking trigger firing and target context, the before/after-target steps, waits, measured exposures and stopping.
- The exposure meter is tested on synthetic stars (noise, hot pixels, saturation, a brighter neighbour), and INDI tracking-off is checked against the real INDI simulator.
- New: every build takes the exact downloads on this page to fresh Windows and Mac machines, unpacks them as a person would, opens them by double-click, loads the first-run page in a real browser (Edge, Chrome), plans a night, rehearses it, double-clicks again and quits. On Windows it also installs N.I.N.A. 3.2.0.9001 from nighttime-imaging.eu and checks its log: *Successfully loaded plugin StarCadence version 0.4.0.0*, with no plug-in errors.
- Still not run in a live N.I.N.A. session with real equipment: reports welcome as GitHub issues, with N.I.N.A.'s log.
